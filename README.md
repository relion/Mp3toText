# Mp3toText

אפליקציית דסקטופ (PySide6 / Qt) להמרת קובצי MP3 לטקסט ולכתוביות SRT באמצעות Gemini, כולל תרגום לשפה אחרת, עם תמיכה מלאה בעברית ובאנגלית (BiDi).

📖 **תיעוד מלא** (הפעלה, תיאור הקוד ותרשימי זרימה): [docs/DOCUMENTATION.md](docs/DOCUMENTATION.md) · גרסת HTML עם תרשימים: [docs/DOCUMENTATION.html](docs/DOCUMENTATION.html)

לבנייה מחדש של ה-HTML אחרי עדכון ה-Markdown: `pip install markdown` ואז `python docs/build_html.py`.

## התקנה
```
pip install -r requirements.txt
```

## הפעלה
לחיצה כפולה על `run.bat` (או `python app.py`).

## שימוש
1. בפעם הראשונה: לחץ **⚙ מפתח API** והדבק את מפתח ה-Gemini (נשמר ב-`config.json` המקומי). לחלופין הגדר משתנה סביבה `GEMINI_API_KEY`.
2. גרור קובץ MP3 לחלון, או לחץ על אזור הקובץ לבחירה.
3. בחר שפת דיבור, ואם רוצים גם כתוביות סמן **צור גם כתוביות (SRT)**.
4. לחץ **▶ המר לטקסט**.
5. **📋 העתק הכל** / **💾 שמור כקובץ** / **🎬 שמור כ-SRT** (עם כיוון "הקדמה" במילישניות).
6. לתרגום: בחר שפה ב-**תרגם ל:** ולחץ **🌐 תרגם**. התרגום מופיע בלשונית "תרגום", והשמירה ממנה מציעה שם כמו `הרצאה.en.srt`.

ניתן לשנות מודל ע"י הוספת `"model": "..."` ל-`config.json` (ברירת מחדל: `gemini-2.5-flash`).

## טוקנים ועלות
- למעלה: סה״כ מצטבר (נשמר ב-`config.json`, כפתור ↺ לאיפוס). בשורת הסטטוס בתחתית החלון: עלות הפעולה האחרונה (ריחוף מציג פירוט).
- המחיר מחושב לפי שכבה בתשלום של `gemini-2.5-flash`: אודיו $1.00, טקסט $0.30, פלט $2.50 למיליון טוקנים. בשכבה החינמית אין חיוב בפועל.
- שער הדולר לשקל: ברירת מחדל 3.7, ניתן לשנות ב-`config.json` עם `"usd_to_ils": 3.65`.
